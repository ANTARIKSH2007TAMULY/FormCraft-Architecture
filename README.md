
# FormCraft Architecture

FormCraft is a **visual form builder web app** built using **HTML, CSS, and Vanilla JavaScript**.  
It lets you **dynamically design and customize a form in the browser**, including adding fields, list items, and structural HTML elements — all without frameworks.

This interactive tool demonstrates strong **DOM manipulation skills**, making it a great college project and **resume showcase** for front-end fundamentals.

---

## 📌 Features

- Live customization of form container styling  
- Add input fields dynamically  
- Add list items (ordered or unordered)  
- Add structural HTML elements (div, headings, section, etc.)  
- Edit form title and labels interactively  
- Export the generated form HTML  
- Fully built with **vanilla JavaScript**, no frameworks

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript (DOM manipulation)

No libraries or frameworks — everything is written in pure, intermediate-level JavaScript.
